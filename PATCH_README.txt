SWA6 ADMIN UI PATCH V3

Что меняется:
- весь рабочий интерфейс на русском;
- вкладки: НОВЫЕ / В РАБОТЕ / ГОТОВО / АРХИВ;
- в закрытой карточке больше нет фотографий товара;
- слева крупно номер заказа SW_N;
- справа сумма, клиент, количество товаров и дата;
- карточка раскрывается вниз на месте, без модального окна;
- внутри раскрытия: товары, размеры, количество, цены, клиент, контакты, доставка, адрес, комментарий, итог;
- никаких CANCEL / SKIP / лишних статусов;
- одна логичная кнопка действия: В РАБОТУ -> ГОТОВО -> В АРХИВ;
- обновлён cache version PWA.

Как применить:
1. Распаковать ZIP.
2. Скопировать папку admin из ZIP поверх папки admin в репозитории.
3. В GitHub Desktop проверить Changes.
4. Commit.
5. Push.

ВАЖНО:
Этот ZIP меняет только интерфейс админки.
Настоящие push-уведомления, которые приходят когда PWA закрыта, требуют отдельного backend-патча:
VAPID + PushSubscription в PostgreSQL + push event в service worker + отправка push сервером при создании заказа.
