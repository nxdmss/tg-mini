SWA6 TURNKEY IPHONE WEB PUSH V5

ЧТО ВНУТРИ
- настоящий Web Push, а не опрос открытой страницы;
- push приходит на iPhone, когда PWA закрыта;
- уведомление: "Новый заказ SW_N" + сумма + имя клиента;
- тап по уведомлению открывает нужный заказ и нужную вкладку;
- подписки устройств хранятся в PostgreSQL;
- подписки доступны только ADMIN / MANAGER;
- умершие push-подписки (404/410) удаляются автоматически;
- кнопка УВЕД. включает/выключает подписку;
- на iPhone приложение само подскажет добавить его на экран Домой;
- VAPID private key генерируется на сервере и НЕ попадает в GitHub;
- сохранены функции v4: статусы назад/вперёд, удаление товара, удаление заказа, возврат остатков.

КАК ПРИМЕНИТЬ
1. Распаковать ZIP поверх корня репозитория.
2. Commit + Push через GitHub Desktop.
3. На сервере:
   ssh swa6admin@158.160.138.84
4. На сервере выполнить:
   cd /opt/swa6/app && git pull --ff-only && chmod +x deploy-web-push.sh && ./deploy-web-push.sh

ПОСЛЕ "ГОТОВО"
На iPhone:
Safari -> https://admin.swagystan.ru -> Поделиться -> На экран Домой.
Открыть SWA6 Orders с иконки, войти, нажать "УВЕД.", разрешить уведомления.

ВАЖНО
- iPhone должен быть iOS 16.4 или новее.
- Для iPhone Web Push веб-приложение должно быть установлено на экран Домой.
- VAPID ключи генерируются один раз. Не удаляйте VAPID_* из backend/.env, иначе старые подписки перестанут работать.
- backend/package-lock.json специально не заменяется этим патчем. Dockerfile использует npm install, чтобы установить web-push по зафиксированной версии без ручной возни с lock-файлом.
