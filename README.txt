Скопируй папку frontend в корень tg-mini с заменой файлов. Фон Zulfia берётся из frontend/public/river.gif. В архиве он временный: присланный 223620(1).gif на самом деле содержит один PNG-кадр, поэтому заменяй river.gif своей настоящей анимированной GIF без изменений кода. river.png используется при настройке уменьшения движения/трафика. Лёгкое размытие и эффект плёнки заданы в ZulfiaBackdrop.css. Проверка: cd frontend && npm install && npm run build.
