Обновление рамки товара Zulfia

Скопируйте папку frontend из этого архива в корень проекта tg-mini-main с заменой совпадающих файлов.

Новая рамка скопирована точно как в присланном JPG: без вырезания фона, замены цветов или масштабирования пропорций. Все содержимое товара расположено в ее бежевой середине. Если описание не помещается, середина прокручивается, рамка остается неподвижной. За рамкой остается речка.

Ваш файл frontend/public/river.gif архив НЕ содержит и НЕ перезаписывает.
