Обновление Zulfia

Скопируйте папку frontend из этого архива в корень проекта tg-mini-main с заменой совпадающих файлов.

Внутри Zulfia возвращен прежний шрифт Regez и исходные размеры карточки. При открытии товара речка остается видимой вокруг рамки и сквозь ее прозрачный центр; внутри рамки затемнение усилено. У кнопки корзины убрана белая заливка.

Ваш файл frontend/public/river.gif архив НЕ содержит и НЕ перезаписывает.
