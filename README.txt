Обновление рамки и шрифтов Zulfia

Скопируйте папку frontend из этого архива в корень проекта tg-mini-main с заменой совпадающих файлов.

Рамка шире: до 680 px на компьютере и на всю ширину телефона. Исходное изображение рамки сохранено без изменений и без растяжения пропорций. Содержимое карточки остается в бежевой середине.

Шрифты и размеры текста магазина Zulfia теперь используют общие правила SWAGYSTAN (IBM Plex Mono и те же размеры товаров, цен, кнопок и описания). Только фирменная надпись «Zulfia» остается рукописной.

Ваш файл frontend/public/river.gif архив НЕ содержит и НЕ перезаписывает.
