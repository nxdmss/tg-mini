1. Скопируй папку frontend в корень tg-mini с заменой файлов. В архиве НЕТ river.gif — твоя анимация останется на месте.
2. Убедись, что настоящий анимированный файл лежит именно в frontend/public/river.gif.
3. В консоли: cd frontend && npm run check:river. Если пишет «только 1 кадр», это статичный GIF; найди оригинальную анимированную GIF.
4. Выполни npm run build, опубликуй обновление и открой на сайте /river.gif?live=3 в отдельной вкладке. Если там нет движения, сервер получил старый/однокадровый файл.
5. Рамка из zulfia-frame.jpg окружает магазин и товар; задний фон — GIF по всему экрану под лёгким размытием и плёнкой.
