Zulfia — рамка карточки на весь экран телефона

Скопируйте папку frontend из этого архива в корень проекта tg-mini-main с заменой файлов.

На телефоне рамка занимает всю высоту и ширину экрана, без полосы речки снизу. Содержимое остается внутри бежевой середины и прокручивается при необходимости. На компьютере рамка сохраняет исходные пропорции и ширину до 680 px. Кнопка «Корзина» теперь без прямоугольной обводки — только текст.

Ваш frontend/public/river.gif архив не содержит и не перезаписывает.
