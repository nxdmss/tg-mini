SWAGYSTAN — BALANCED TYPOGRAPHY / ПОЛНАЯ ЗАМЕНА ИЗМЕНЁННЫХ ФАЙЛОВ

Заменены прежние резкие настройки жирности и обводки на ровные.
- Цифры IZLOM везде, включая поиск и поля оформления заказа.
- Рубли, цифры и цены в каталоге в единой средне-жирной типографике.
- Названия товаров, категории, поиск и подписи — умеренная читабельная насыщенность.
- Сердца без подложки поверх фотографий и карточек товаров.
- «О нас»: KIZILURT | DAGESTAN сверху и снизу, каждая надпись в одну строку.

ВАЖНО: IZLOM_Narrow не содержит знака рубля ₽, поэтому знак берётся из
IBM Plex Mono. CSS выравнивает визуальную толщину этих разных шрифтов.

Это архив с полными изменёнными исходниками, а не сборка dist.
Распакуй в КОРЕНЬ проекта с заменой файлов и отправь в GitHub.
Шрифт IZLOM сохраняется из предыдущих версий — проверь наличие:
frontend/public/fonts/IZLOM_Narrow-Regular.woff2
frontend/public/fonts/IZLOM_Narrow-Regular.ttf

На сервере после GitHub (когда изменения уже в main):
cd /opt/swa6/app && git pull --ff-only && cd frontend && npm ci && npm run build && sudo cp -a dist/. /var/www/swagystan/

Не стирай frontend/.env.production — там адрес API.
